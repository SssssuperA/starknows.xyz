## 使用命令

在知识库根目录运行，需要 Python 3 和 Node.js 22 或以上：

```bash
# 构建、核验全部来源及总结，再执行 Wrangler 预检（不上传）
python3 tools/cloudflare_site.py check

# 本地预览云端版本：http://127.0.0.1:8787
python3 tools/cloudflare_site.py preview

# 登录官方 Cloudflare 授权页；只需要首次或凭据过期时执行
python3 tools/cloudflare_site.py login

# 回调不便时可以使用设备授权
python3 tools/cloudflare_site.py login --device

# 核对当前登录
python3 tools/cloudflare_site.py whoami

# 重新构建并实际发布，绑定 starknows.xyz
python3 tools/cloudflare_site.py deploy
```

工具优先复用本次放在系统临时目录中的独立 Node 22.23.4 与 Wrangler 4.152.0；若临时工具已被清理，则使用本机 Node 22+ 和 `npx wrangler@4.152.0`。Wrangler 状态、日志与登录凭据保存在系统临时目录的 `starknows-cloudflare-tools` 中，以受限权限创建，不保存在知识库内；系统清理后可能需要重新登录。不要分享该临时工具目录。

每次 `check`、`preview`、`deploy` 都重新构建，默认输出系统临时目录下的 `starknows-cloudflare-build`。仅上传其中的 `public/`。`publication-manifest.json` 留在发布目录外层，用于核对每份报告的哈希、大小与是否上传。构建失败时脚本停止，不发布旧包。

发布前检查每份 PDF 的 SHA256、发布清单、format 2 总结及来源页数；5 份历史总结缺少嵌套来源字段，仅对固定报告 ID 使用对应的完整文字抽取记录核验，不修改研究内容。发现源文件已改变、总结缺失或总结未同步时拒绝发布。
